## 🚀 Projeto em destaque

### Help Desk

Sistema web para gerenciamento de chamados desenvolvido com **Node.js, Express e SQLite**.

O projeto conta com:

- API REST
- Cadastro e login de usuários
- Autenticação com JWT
- Senhas protegidas com bcrypt
- Perfis `user` e `admin`
- Controle de acesso por usuário
- CRUD de chamados
- Filtros por status e prioridade
- Histórico de mensagens
- Interface web integrada à API

[➡️ Ver projeto no GitHub](https://github.com/caiogonzagasm/helpdesk-api)
